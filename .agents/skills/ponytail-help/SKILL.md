# Ponytail commands

Ponytail is explicit-only and applies to one request. It does not persist or change the response format.

| Command | Purpose |
| --- | --- |
| ponytail | Implement or review the simplest complete solution. |
| ponytail-review | Review a diff for unnecessary complexity. |
| ponytail-audit | Audit a repository for unnecessary complexity. |
| ponytail-debt | Inspect deliberate shortcut comments. |
| ponytail-gain | Show the skill's historical benchmark summary. |

Use `$name` in Codex or `/name` in Claude where the skill is available. These commands never authorize dropping requested functionality or unrelated edits.
