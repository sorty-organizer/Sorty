# Editing examples

Use these examples only when the short checklist leaves a wording problem unresolved. Preserve facts, deliberate style, and the author's voice.

| Pattern | Better approach |
| --- | --- |
| "It is important to note that the build passed." | "The build passed." |
| "This serves as a testament to improved performance." | State the measured timing or omit the claim. |
| "Experts agree this is a major improvement." | Name and link the source, or remove the attribution. |
| "The database stays close at hand." | Explain where data is stored and how it is accessed. |
| "Not just faster, but a new paradigm." | State the actual change and its effect. |
| Repeated headings, bold labels, and groups of three | Keep the structure needed to scan the content. |
| "Could potentially possibly reduce latency." | State the uncertainty once and give the evidence. |

Keep technical identifiers and quotations accurate. Prefer a precise caveat over unsupported confidence. Do not invent anecdotes, opinions, or emotional reactions to make the text sound human.
